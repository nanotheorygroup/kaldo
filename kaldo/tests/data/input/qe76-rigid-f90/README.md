# QE `rigid.f90` synthetic reference generator

This directory documents the provenance of `../../qe76_rigid_f90_reference.npz`.
It is **not** a `pw.x`, `ph.x`, `q2r.x`, or 24-calculation DFPT data set.  It
calls the QE `rigid` module directly with the synthetic values from
`test_qe_q2r_nac.py`; therefore no truthful `pw.x` inputs exist to include.

Run `QE_RIGID_F90=/path/to/qe-7.6/PHonon/PH/rigid.f90 bash run.sh
/tmp/qe76-rigid-f90`. The wrapper compiles the unmodified QE 7.6 source only after
checking SHA-256 `c2da58dfa6849c4edb6f96ad8ad2be58834ae23142bdac2ee33eeebf1eb21e88`,
which is the fixture's recorded QE 7.6 source hash. `kinds_constants.f90`
only supplies the QE module interfaces required to compile that source; it
does not contain an implementation of `rgd_blk`.

The checked-in NPZ is generated by this wrapper. The 3D finite, direct-Gamma,
directional-Gamma, negative-sign, and 2D finite arrays were all emitted by the
unmodified QE routine and are retained as provenance. This PR implements and
tests only the three-dimensional finite-q and directional-Gamma behavior; it
does not claim support for QE's separate two-dimensional LO--TO treatment.
